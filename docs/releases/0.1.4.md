# Music telemetry 0.1.4

For YouTube Music **8.40.54**, with ReVanced Manager **2.6.0 or newer**.

## Changes

- Observe native queue insertions, removals, and reorders in addition to replacements and content updates.
- Reconcile the queue after song changes and asynchronous playlist or mix loading, with a five-second fallback and a one-minute snapshot heartbeat.
- Include the active song in queue snapshot deduplication, so moving through an unchanged queue still emits an event.
- Upload accumulated events in bounded batches without the previous one-event-per-second drain delay; cap retry backoff at 15 seconds.

## Install

Refresh the existing ReVanced Manager source:

`https://raw.githubusercontent.com/ThetaBird/revanced-telemetry/main/patches.json`

Repatch the original YouTube Music 8.40.54 APK and reinstall it using the same signing identity. Select **Native playback queue telemetry** alongside the existing telemetry patches; non-root installs also need **GmsCore support**. The attached `.rvp` is the patch bundle, not a preconfigured app. Configure the collector in **Settings → Listen telemetry**.

## Validation

The release workflow builds and tests the bundle. Local verification includes Kotlin patch tests, Python packaging tests, Android instrumentation, and a successful 8.40.54 APK patch with emitted-DEX hook audit. Live queue latency on a physical host device still requires an updated app install and observation.
