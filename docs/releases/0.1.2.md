# Music telemetry 0.1.2

For YouTube Music **8.40.54**, with ReVanced Manager **2.6.0 or newer**.

## Changes

- Capture the full loaded playback queue as `playback_queue`, preserving song order, duplicates, queue IDs and available metadata.
- Capture opened playlists as `playlist_snapshot`, including loaded off-screen songs, video/occurrence/browse IDs, text, descriptions and mapped artwork.
- Record playlist entry as `music_action` / `playlist_playback_started` when playlist context matches a loaded track.
- Record song/queue/off repeat-button selections as `repeat_mode_changed`, with numeric `repeatMode` and readable `repeatModeName`.
- Record accepted Up Next song clicks as `queue_song_selected`, retaining the selected song and queue occurrence separately from the current player.
- Revalidate existing `like`, `dislike` and `remove_rating` hooks with exact request targets.
- Preserve retry IDs, chunk large snapshots, retain partial-source scope during reassembly and report sanitized capture failures.

## Install

Refresh the existing ReVanced Manager source:

`https://raw.githubusercontent.com/ThetaBird/revanced-telemetry/main/patches.json`

Repatch the original YouTube Music 8.40.54 APK. Select **Native playback queue telemetry**, **Opened playlist snapshots**, **Repeat mode telemetry**, and **Playback queue selection telemetry** alongside the core telemetry patch and any existing optional patches. Keep the same signing identity when updating an installed APK.

The attached `.rvp` is the patch bundle. Its `.sha256` attachment provides the checksum. Configure the collector in **Settings → Listen telemetry**; the bundle contains no collector credentials.

## Receiver and coverage

Deploy the companion Listen receiver change [`91f5cde`](https://github.com/ThetaBird/listen/commit/91f5cde) before sending `playback_queue`. All action events use the existing private `music_action` path and do not affect public now-playing.

App snapshots contain currently loaded data and carry `complete: false`; they do not force playlist pagination. Unmapped/opaque YouTube metadata is omitted. Rating events observe request construction, playlist entry observes a track load, and queue clicks observe command dispatch—not confirmed server acceptance or audible playback. Signed-in live UI behavior remains unverified.
