# Music telemetry 0.1.3

For YouTube Music **8.40.54**, with ReVanced Manager **2.6.0 or newer**.

## Changes

- Capture native queue replacements and content updates directly, rather than waiting for a later media-session refresh or Up Next interaction.
- Retain the media-session capture hook for in-place item metadata and selection updates.
- Reject unsupported queue-mutation bytecode layouts before injecting any hooks.
- Require both direct native queue hooks in the emitted APK audit.

## Install

Refresh the existing ReVanced Manager source:

`https://raw.githubusercontent.com/ThetaBird/revanced-telemetry/main/patches.json`

Repatch the original YouTube Music 8.40.54 APK and reinstall it using the same signing identity. An already-installed 0.1.2 APK will not gain the earlier queue capture from the Listen API update alone. Select **Native playback queue telemetry** alongside the existing telemetry patches; non-root installs also need **GmsCore support**.

The attached `.rvp` is the patch bundle, not a preconfigured app. Its `.sha256` attachment provides the checksum. Configure the collector in **Settings → Listen telemetry**.

## Validation

The release workflow builds and tests the bundle. Local verification includes Kotlin patch tests, Python packaging tests, Android instrumentation, and a successful 8.40.54 APK patch with emitted-DEX hook audit. Live queue latency on a physical host device still requires an updated app install and observation.
